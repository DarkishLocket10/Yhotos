## Contradictory license requirements

The brief requires both:

- `workspace.package.license = "AGPL-3.0-only"`.
- A cargo-deny license allow list containing `AGPL-3.0`, with every other
  license denied, and a passing `cargo deny check`.

Cargo-deny 0.20.2 treats these identifiers separately. With the prescribed list,
`cargo deny check` rejects all 14 workspace packages:

```text
license = "AGPL-3.0-only"
rejected: license is not explicitly allowed
```

The `AGPL-3.0` allowance is reported as unmatched. SPDX deprecates that identifier:
<https://spdx.org/licenses/AGPL-3.0.html>.

Decision needed: permit `AGPL-3.0-only` in the allow list to match the workspace
license. The literal requested policy remains in `deny.toml`; no exception or
license-check bypass has been added. Implementation stopped under the AGENTS.md
rule for contradictory briefs.
