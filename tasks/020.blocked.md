## Conflict

- `tasks/020-admin-library.md`, Design / Pages, requires the album editor to offer
  `public`, `restricted`, and `inherit` visibility.
- `docs/architecture.md`, section 4, defines album visibility as
  `public|restricted`. It separately gives photos the three values
  `inherit|public|restricted`. The document says it is binding and requires a
  documentation change first when its design needs to change.
- `crates/yhotos-db/migrations/20261021000100_schema.sql:49` enforces that
  distinction with `CHECK (visibility <> 'inherit')` on albums.
- `AGENTS.md` forbids editing the architecture to match an implementation and
  directs an agent to stop and record a contradictory brief here.

This is a conflict in the permitted authorization model, rather than a missing
manifest entry or an ordinary migration needed to implement an agreed model.
Dropping the constraint would implement the brief but depart from the binding
architecture; omitting the choice would implement the architecture but not the
brief. The core `Visibility` enum already contains `Inherit`, so the problem is
not a missing enum variant.
