Synthetic 1.2-second, 128x96 10fps moving test pattern with a generated 880Hz tone.
All three files are below 300 KB. No camera footage or personal metadata.

Generated locally with ffmpeg 6.1.1:

```
ffmpeg -f lavfi -i testsrc2=size=128x96:rate=10 -f lavfi -i sine=frequency=880:sample_rate=44100 -t 1.2 -c:v libx264 -profile:v high -pix_fmt yuv420p -c:a aac -b:a 32k -movflags +faststart h264.mp4
ffmpeg -display_rotation:v:0 90 -i h264.mp4 -c copy rotated.mov
ffmpeg -i h264.mp4 -c:v libx265 -x265-params pools=1:frame-threads=1:log-level=error -c:a copy -tag:v hvc1 hevc.mov
```

`rotated.mov` has a 90-degree display matrix, representing iPhone-style portrait
orientation without rotating stored pixels. Malformed files are generated by tests;
the duration rejection uses this same real sample with a one-second configured cap.

The 4K publication regressions use a synthetic five-frame, one-second HEVC MOV
at 3840x2160, and a copy with a 90-degree display matrix. Both are under 300 KB.
Generated locally with the digest-pinned static ffmpeg from `deploy/dev/video-tools.sh`:

```
target/video-tools/ffmpeg -v error -f lavfi -i color=c=navy:s=3840x2160:r=5:d=1 -c:v libx265 -preset ultrafast -x265-params pools=1:frame-threads=1:log-level=error -pix_fmt yuv420p -tag:v hvc1 -an -map_metadata -1 4k-landscape.mov
target/video-tools/ffmpeg -v error -display_rotation:v:0 90 -i 4k-landscape.mov -c copy 4k-portrait.mov
```
